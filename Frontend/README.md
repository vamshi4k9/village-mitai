# Village Mitai — Frontend

React storefront and staff dashboards for Village Mitai.

```bash
pnpm install
pnpm run dev      # http://localhost:3000
pnpm run build    # production build into ./build
```

Before the first run, create `.env` with `REACT_APP_MAPBOX_TOKEN` and check `API_BASE_URL` in [src/constants.js](src/constants.js).

Full guide: [docs/FRONTEND.md](../docs/FRONTEND.md). Repository overview: [README.md](../README.md).
